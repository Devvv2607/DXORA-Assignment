## Notes on how pages were read

- The Bluesky doc pages (`docs.bsky.app`) now redirect to `bsky.network/docs/...` and `endpoints.bsky.app` (a Scalar viewer).
  The endpoint details come from the OpenAPI document that viewer loads (`openapi.bluesky-app.json`) and the lexicon JSON in
  Bluesky's `atproto` repository.
- The Telegram reference is one very large page. The relevant sections were extracted from its HTML by anchor.
- The Dev.to reference is client-rendered. Its downloadable OpenAPI YAML (linked from the page) was parsed directly.
